# 지출 기록 — 잠금화면에서 한 줄

안드로이드 잠금화면 알림을 누르면 입력 화면이 바로 뜹니다. `커피 4500` 을 적으면
지출 한 줄이 저장되고, **오늘 쓸 수 있는 돈**이 그 자리에서 줄어듭니다.
엔터를 칠 때마다 한 건씩 들어가므로 장보기처럼 여러 건도 이어서 적습니다.

곳간은 **개인**과 **공용** 둘이고 서로 섞이지 않습니다.

```
잠금화면 알림 ──탭──▶ 빠른 입력 화면 ──엔터──▶ 파싱 ──▶ Firestore 한 줄
                                  ▲                          │
                                  └── 오늘 쓸 수 있는 돈 갱신 ◀─┘
```

**저장은 구글 로그인을 따라옵니다.** 토큰이나 DB 주소를 입력할 것이 없습니다 — 로그인하면
개인 곳간이 바로 열리고, 공용 곳간은 배우자와 «가정 코드»로 한 번 묶으면 열립니다.
Firestore 는 오프라인에서도 쓰기가 되므로 지하철에서도 기록이 실패하지 않습니다.

## 1. 준비할 것

**없습니다.** 구글 계정으로 로그인하면 개인 곳간이 바로 열립니다.

공용 곳간(같이 쓰는 생활비)만 한 번의 준비가 필요합니다 — 설정의 **공용 곳간 동기화**에서
한 사람이 «코드 만들기»를 누르고, 상대가 그 코드를 «코드로 연결»에 넣으면 됩니다.
묶기 전까지는 기록할 때 곳간을 고르지 않고 개인 곳간 하나로만 동작합니다.

## 3. 앱 설정

1. 앱 실행 → **구글 로그인**
2. 설정 → **예산 주기** → 월급날 (1~31). 달력 월로 쓰려면 `1`
3. 설정 → **개인 곳간** → 이름 · 한 달 예산 (`930000` 도 `93만` 도 됩니다)
4. **공용 곳간**을 쓸 거면 → **공용 곳간 동기화**에서 배우자와 코드로 묶고, 예산을 정합니다
5. **저장** → **알림 켜기** → 알림 권한 허용

화면 맨 위에 곳간마다 오늘 쓸 수 있는 돈이 표시됩니다. 앱을 열 때마다 저장소를 다시 읽어 맞춥니다.

## 4. 사용

잠금화면 알림의 **기록** 을 누르고 입력합니다.
곳간을 둘 다 연결했다면 버튼이 **개인** / **공용** 두 개로 갈립니다 — 타이핑은 그대로고 누르는 위치만 다릅니다.
하나만 연결했으면 고르게 하지 않습니다.



| 입력 | 결과 |
|---|---|
| `커피 4500` | 커피 / 4,500원 |
| `점심 김밥 6000` | 점심 김밥 / 6,000원 |
| `4500 커피` | 커피 / 4,500원 |
| `택시 12,000원` | 택시 / 12,000원 |
| `커피 4천` | 커피 / 4,000원 |
| `장보기 1.5만` | 장보기 / 15,000원 |

규칙은 **마지막 숫자 토큰이 금액, 나머지가 이름**입니다.

결과는 같은 알림에 바로 돌아옵니다.

```
✓ 커피 4,500 · 오늘 쓸 수 있는 돈 41,000     ← 잠금화면 (접힌 상태)

✓ 커피 4,500원 기록됨 · 오후 3:21            ← 펼쳤을 때
오늘 쓸 수 있는 돈 41,000원
하루치 30,000 + 곳간 23,400 − 오늘 12,400
```

## 5. 곳간

곳간의 **이름은 자유롭게 정할 수 있습니다.** «재호 용돈», «우리집» 처럼요 — 알림 버튼과 현황에 그 이름이 그대로 나옵니다. 비워 두면 «개인» · «공용» 을 씁니다. 잠금화면 버튼 두 개가 한 줄에 들어가야 해서 8자까지만 받습니다.

곳간은 **둘**이고 **서로 섞이지 않습니다.** 공용에서 크게 초과해도 개인 하루치는 1원도 줄지 않고, 반대도 마찬가지입니다. 섞기 시작하면 "네 용돈에서 얼마 내"가 앱 안으로 들어옵니다. 공용이 모자라면 공용 하루치가 남은 날 동안 줄어들 뿐이고, 그걸 어떻게 할지는 대화로 정하는 겁니다.

아래 규칙은 곳간마다 독립적으로 돕니다.

### 주기는 월급날부터

예산은 **월급날을 경계로** 리셋됩니다. 25일이면 25일부터 다음 달 24일까지가 한 주기이고, 그 마지막 날(24일)이 **목표일**입니다. 달력 1일 기준으로 쓰려면 월급날에 `1`을 넣으세요.

달력 1일이 아니라 월급날을 쓰는 이유는 실제로 돈이 그렇게 들어오기 때문입니다. 25일에 받는데 1일에 리셋되면, 매달 24일까지는 지난달 돈으로 이번 달 예산을 쓰는 셈이 됩니다.

기록하면 두 가지가 돌아옵니다.

```
오늘 쓸 수 있는 돈 41,000원          ← 지금 괜찮은가
9월 24일까지 542,400원              ← 이 페이스로 가도 되는가
 · 남은 22일 (하루 24,654)
```

### 하루치와 곳간

예산을 그 주기의 일수로 나눈 값이 **하루치**입니다. 하루치를 다 안 쓰면 남은 만큼이 **곳간**에 쌓이고, 다음 날 쓸 수 있는 돈이 그만큼 늘어납니다. 절약의 보상이 월말이 아니라 다음 날 아침에 옵니다.

넘겼을 때는 비대칭으로 처리합니다.

```
곳간 += 하루치 − 그날 지출

곳간이 음수가 되면
    모자란 만큼만 그 주기 남은 날에 나눠 하루치를 낮춘다
    곳간은 0 으로
```

곳간이 먼저 흡수하기 때문에 크게 쓴 다음 날에도 "오늘 쓸 수 있는 돈"이 음수로 남지 않습니다. 마이너스 잔고는 계획이 아니라 판결문이라 앱을 안 열게 만듭니다.

월급날이 오면 하루치가 원래대로 돌아가고, 곳간은 **하루치 5일분까지만** 다음 주기로 넘어갑니다. 무한히 쌓여 예산이 무의미해지는 것과, 주기 끝에 "어차피 사라지니 쓰자"가 되는 것을 둘 다 막습니다.

곳간은 저장소에 없고 앱에만 있습니다. 앱을 지우면 곳간은 0부터 다시 쌓입니다 — 과거를 소급해 복원하지 않습니다.

**적지 않으면 곳간이 부풀어 숫자가 거짓말을 합니다.** 이건 버그가 아니라 의도한 손해입니다. 앱이 잔소리하는 대신, 안 적으면 내 도구가 나에게 쓸모없어집니다.

## 6. 삼성(One UI) 확인 사항

잠금화면 위로 화면을 띄우는 것 자체는 표준 API지만, One UI는 기본 설정이 잠금화면 내용을 가립니다.

- **설정 → 알림 → 잠금화면 알림** → *내용 표시* 켜기
- **설정 → 알림 → 고급 설정 → 알림 아이콘만 표시** 끄기
- **설정 → 배터리 → 백그라운드 사용 제한** 에서 이 앱을 **제한 안 함**으로 (절전 모드가 알림을 죽입니다)

그래도 알림을 눌렀을 때 잠금 해제를 요구한다면, 그건 기기 정책이라 앱에서 우회할 수 없습니다.
지문 한 번 찍고 입력하는 형태가 됩니다.

## 7. 문제 해결

| 증상 | 원인 |
|---|---|
| `로그인이 풀렸습니다` | 구글 로그인이 만료됐습니다. 설정에서 다시 로그인하세요 |
| `공용 곳간이 아직 배우자와 묶이지 않았습니다` | 설정 → 공용 곳간 동기화에서 코드로 먼저 묶으세요 |
| 곳간 숫자가 «—» | 그 곳간에 한 달 예산을 아직 안 정했습니다 |
| 다른 기기에서 적은 게 안 보임 | 앱을 열면 맞춰집니다. 잠금화면 기록은 로컬 사본만 갱신합니다 |
| 재부팅 후 알림 사라짐 | 배터리 최적화에서 앱을 제외하세요 |
| 평문 저장 경고가 뜸 | 기기 키스토어 문제. 앱 전용 저장소라 다른 앱은 못 읽지만, 루팅 기기라면 주의하세요 |

## 보안

- 지출은 Firestore 의 내 계정 아래에만 저장됩니다(공용 곳간은 묶인 가정 아래). 규칙은 `firestore-rules-to-add.txt` 참고.
- 설정은 `EncryptedSharedPreferences`(AES-256)로 저장하며, 기기 키스토어 초기화에 실패하면 앱 전용 평문 저장으로 내려앉고 설정 화면에 경고를 띄웁니다.
- `ReplyReceiver` 는 `exported=false` 라 다른 앱이 호출할 수 없습니다.
- 디버그 서명 APK입니다. 배포용이 아니라 개인 사용 목적입니다.
