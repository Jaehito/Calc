# 병렬 에이전트 동시성 (파일 충돌 방지)

> Claude Code 전용 (`Agent`·워크트리·`TaskStop` 기반). `.cursor`·`AGENTS.md`와 무관 — 동기화하지 않는다.

## 원칙

- **조정자(메인) = 유일한 락.** 에이전트끼리는 락·신호를 주고받지 못한다. 충돌은 **해결**이 아니라 **dispatch 시점 예방**이 1순위.
- 리소스는 **복구 가능성**으로 분류한다 — 복구 불가는 직렬로 예방, 복구 가능은 병렬 두고 통합만 직렬.
- 범용 원칙: **대기보다 멈추고 재실행** (놀며 대기하는 에이전트는 컨텍스트·토큰만 잡고, 재개해도 낡은 상태를 든다).

## 리소스 분류

| 리소스 | 복구 | 병렬 | 정책 |
|--------|------|------|------|
| 씬(`.unity`)·SO(`.asset`)·Unity MCP | ❌ 불가 | ❌ | **단일 리스** — 한 번에 1 에이전트만 Unity 접근. 나머지는 큐 대기(실행 안 함) |
| PlayMode 실행 (원본) | ✅ 가능 | ❌ | 사용자 소유 — 에이전트는 **대기하지 않고 즉시 포기**하고 보류 보고 |
| PlayMode 실행 (검증 agent) | ✅ 가능 | ❌ | 한 번에 1런. 메인은 **짧게 대기**, 서브에이전트는 즉시 포기 |
| 검증(테스트 실행) 권한 | — | ❌ | **오케스트레이터 단독** — 서브에이전트는 `run_tests` 호출 금지. 턴 끝에 1회 배치 (`.claude/rules/playtest.md`) |
| 순수 C# 코드 (git 추적) | ✅ 가능 | ✅ | 워크트리 격리로 병렬, **병합만 직렬** |
| 기획문서 **쓰기** | ✅ 가능 | ❌ | 직렬 — 한 에이전트에 몰기 |
| 기획문서·코드 **읽기** | — | ✅ | 무제한 병렬 (읽기는 충돌 아님) |

## 씬·SO·MCP — 예방 (해결 아님)

- 조정자는 씬/SO/MCP 작업 에이전트가 **실행 중이면 두 번째를 실행하지 않는다** (큐 대기).
- 실수로 둘 다 **씬·SO 파일을 쓰는 중**이면 → **나중 에이전트 `TaskStop`** → 앞 완료·씬 상태 확인 → 재실행. (기다림 금지 — 손상은 회복 안 됨)
- **PlayMode 실행 충돌은 `TaskStop` 금지** — 진행 중인 런을 죽이면 스크린샷·판정이 통째로 버려진다. 단 **기다릴지 포기할지는 점유자에 따라 갈린다**: 사용자 Play(길다)면 즉시 포기하고 보류 보고, 다른 검증 런(수십 초)이면 짧게 대기. 서브에이전트는 어느 쪽이든 포기. 정책·락·대기 스크립트 SSOT는 `.claude/rules/playtest.md`.
- 코드 병렬 에이전트를 워크트리로 격리할 때도 **씬·SO 파일은 워크트리에서 제외** (병합 불가).

## 코드 — 병합만 직렬

- 서로 다른 폴더 C# 편집은 병렬 허용. 작업 도중 멈춤·대기 없음.
- 병합은 **먼저 끝난 쪽 먼저**, conflict marker는 **병합 시점에만** 해결.
- **허브 파일**(`BattleLayout.cs`, `*StateMachine`, `PlayingCardAbilityExecutor` 등 여러 기능이 조립되는 파일)은 **단독 소유자 1명** 지정. 다른 에이전트가 건드려야 하면 멈추고 소유자 경유.

## 멈춤 vs 대기

| 상황 | 판단 |
|------|------|
| 기본 (필요한 파일을 다른 에이전트가 잡음) | **멈추고 재실행** — 소유자 완료 후 새 컨텍스트로 재개(변경 반영됨) |
| 거의 완료·재작업 비용이 큼 | 예외적 **짧은 대기** 허용 |
| 씬·SO **파일 쓰기**가 이미 겹침 | 즉시 **`TaskStop`** (대기 금지) |
| **사용자가 원본에서 Play 중** | **즉시 포기** (`TaskStop`·대기 금지) — 보류 보고 후 종료 |
| **agent에서 다른 검증 런 중** | 메인만 **짧게 대기** (`.claude/scripts/unity-playmode-wait.ps1`), 서브에이전트는 포기 |

## 소유권 매니페스트 (선택)

병렬 코드 에이전트가 많을 때만 사용. 스크래치패드에 `경로 → 소유 에이전트` 파일 하나를 두고, 조정자가 dispatch 전 확인해 겹치면 실행하지 않는다. 씬/SO는 `Unity 전체 = 단일 리스` 한 줄로 표기. 소수 에이전트면 조정자의 순차 판단으로 충분 — 강제 아님.
